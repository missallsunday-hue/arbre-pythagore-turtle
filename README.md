# Arbre de Pythagore avec Python (turtle)

Dessin d'une fractale récursive : sur chaque carré, un triangle rectangle
dont l'hypoténuse est le côté du carré, puis deux nouveaux carrés sur les cathètes.

## Maths
c1 = c·cos(a), c2 = c·sin(a)  ->  c1² + c2² = c² (théorème de Pythagore).
Chaque niveau a la même aire totale.

## Lancer
python arbre_pythagore.py

## Commandes
- ← / → : changer l'angle
- ↑ / ↓ : changer la profondeur
